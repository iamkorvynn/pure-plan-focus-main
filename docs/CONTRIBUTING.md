# 🤝 Contributing to Pure-Plan-Focus

We welcome contributions of all types! Whether you're fixing a bug, suggesting a new feature, or improving documentation, your help is appreciated.

---

## 🛠️ How to Contribute

### 1. Report Bugs
If you find a bug, please create an issue with:
- A clear, descriptive title.
- Steps to reproduce the bug.
- Actual vs. expected behavior.
- Screenshots if applicable.

### 2. Suggest Features
Have an idea for a new module or widget?
- Check if the idea has already been suggested.
- Describe the feature in detail and why it would be useful.

### 3. Pull Requests (PRs)
Ready to make a change?
- Fork the repository and create your branch from `main`.
- Ensure your code follows the existing style (ESLint & TypeScript).
- Run all tests (`npm test` and `npm run test:watch`) before submitting.
- Provide a clear description of your changes and cross-reference any related issues.

---

## 🎨 Style Guide

- **TypeScript**: Use strict typing where possible. Avoid `any`.
- **Styling**: Stick to the Tailwind CSS utility-first approach and Shadcn UI components.
- **State Management**: Use the established Context API patterns for global state and React Query for server data.
- **Testing**: Add unit tests for new utility functions and integration tests for major UI components.

---

## 📜 Code of Conduct

All contributors are expected to follow our Code of Conduct (be respectful, avoid offensive language, and maintain a collaborative spirit).
